# 前端视觉设计规范（Yohaku 风格）

> 所有组件只引用 `src/styles/global.css` 中的设计令牌（CSS 自定义属性），不写临时数值。新增或修改界面前先对照本规范；提交说明中注明遵循的条目（如 `§2 字号`、`§6 动效`）。

## 1. 颜色

| 令牌                  | 浅色            | 深色          | 用途                                             |
| --------------------- | --------------- | ------------- | ------------------------------------------------ |
| `--paper`             | `#faf9f5`       | `#18181a`     | 页面底色（纸）                                   |
| `--n-1 … --n-10`      | 暖灰阶          | 同阶反转      | 中性色基础                                       |
| `--ink-strong`        | `--n-10`        |               | 标题                                             |
| `--ink`               | `--n-9`         |               | 正文                                             |
| `--ink-muted`         | `--n-7`         |               | meta、次要文字                                   |
| `--ink-faint`         | `--n-6`         |               | 占位、辅助                                       |
| `--border` / `--hair` | 10% / 8% 墨色   | 白色 10% / 7% | 发丝线，0.5–1px                                  |
| `--surface-1`         | 墨色 2.6%       | 白 3%         | 代码块、引用等极淡底                             |
| `--surface-2`         | 墨色 5%         | 白 6%         | hover 底                                         |
| `--accent`            | `#c56473`（梅） | 同            | **唯一强调色**：链接 hover、当前态、焦点环、徽标 |

- 强调色只用于点睛（≤ 一屏一两处），不做大面积填充；透明梯度用 `--accent-8/12/30`。
- **Dock 图标色板**是唯一允许的多彩区域，每个图标一个柔和渐变（浅 → 深，160°），深色模式整体降亮度：
  首页 梅红 `#e29aa5→#c56473`、文章 靛蓝 `#9fb1e0→#5f73b8`、随笔 琥珀 `#eccb86→#c9973f`、关于 青绿 `#9fcbbb→#5d9483`、语言 紫 `#c2aee0→#8565b5`、主题 石板 `#a9b3c4→#5f6b80`。

## 2. 字体与字号

- 正文与标题：`--font-serif`（Noto Serif SC）；UI：`--font-sans`；代码、meta、日期、角标：`--font-mono`（JetBrains Mono）。
- 字号阶梯（只用这些）：

| 令牌                             | 值                       | 用途                                             |
| -------------------------------- | ------------------------ | ------------------------------------------------ |
| `--fs-2xs`                       | 10.5px                   | mono 角标、kicker                                |
| `--fs-xs`                        | 11.5px                   | mono meta、徽标、文件名标签                      |
| `--fs-sm`                        | 12.5px                   | 图注、提示气泡、表格表头                         |
| `--fs-meta`                      | 13.5px                   | 返回链接、上一篇/下一篇、按钮、评论 meta         |
| `--fs-md`                        | 14px                     | UI 正文（代码块用 `--fs-meta`，行内代码 0.86em） |
| `--fs-ui`                        | 15px                     | 列表摘要、评论正文                               |
| `--fs-body`                      | 16px                     | 文章正文                                         |
| `--fs-lg / xl / 2xl / 3xl / 4xl` | 18 / 21 / 30 / 32 / 44px | 标题层级                                         |

- 行高：`--lh-tight 1.25`（标题）、`--lh-ui 1.5`（UI）、`--lh-body 1.85`（正文）、`--lh-code 1.7`（代码）。
- 数字用 `font-variant-numeric: tabular-nums`；英文大写 mono 标签字距 0.08–0.12em。

## 3. 间距

4px 基准：`--sp-1 4` · `--sp-2 8` · `--sp-3 12` · `--sp-4 16` · `--sp-5 24` · `--sp-6 32` · `--sp-7 48` · `--sp-8 64` · `--sp-9 96`。留白是主要材料：区块之间 ≥ `--sp-7`，同组元素 `--sp-2`–`--sp-3`。

## 4. 圆角

`--r-xs 4px`（行内代码、kbd）· `--r-sm 8px`（小块）· `--r-md 12px`（代码块、图片、缩略图、卡片）· `--r-pill 9999px`（按钮、标签、提示气泡、Dock 容器）· `--r-round 50%`（头像、图标）。可点击的独立控件一律胶囊或圆形。

## 5. 阴影

内容区不用阴影，只靠发丝线分层。浮层才用：`--shadow-float`（Dock、灯箱）、`--shadow-pop`（提示气泡、小浮钮）。

## 6. 动效

- 曲线 `--ease: cubic-bezier(0.22, 1, 0.36, 1)`（减速），**禁止回弹 / overshoot**。
- 时长：`--dur-1 80ms`（按压、旧页淡出）· `--dur-2 200ms`（hover、颜色、新页淡入）· `--dur-3 300ms`（主题、展开）· `--dur-4 450ms` · `--dur-5 700ms`。
- 只动 `transform` / `opacity`；JS 驱动的动画用与时间相关的指数插值（临界阻尼），收敛后停止 rAF。
- `prefers-reduced-motion: reduce` 时关闭位移、缩放与页面过渡，仅保留颜色变化。

## 7. 组件

- **链接**：正文链接墨色 + 1px 下划线（`--accent-30`），hover 变 `--accent`；导航类链接无下划线。
- **按钮**：胶囊，`--fs-meta`，高 32–36px，发丝线边框，hover `--surface-2`；主按钮也不用实心大色块。
- **返回链接 / 上下篇**：返回链接为衬线 `--fs-meta`、`--ink-muted`，hover `--accent`；上下篇不用卡片，两栏，标签 mono `--fs-2xs` 大写 `--ink-faint`，标题衬线 `--fs-md`。
- **代码块**：无窗口边框、无阴影、无标签栏；底色 `--surface-1`，圆角 `--r-md`；`--fs-meta` 的 JetBrains Mono，行高 `--lh-code`；文件名为右上角 mono `--fs-xs` 弱色小标签；复制按钮为 hover 才出现的幽灵图标；高亮行用 `--accent-8` 轻底 + 左侧 2px 细条。终端框仅在显式指定 `frame="terminal"` 时显示。
- **行内代码**：`--surface-2` 底、`--r-xs`、0.86em，无边框。
- **表格**：只用横向发丝线，表头 `--fs-sm` mono 弱色；宽表横向滚动。
- **提示块（Alert）**：左侧 2px 色条 + 极淡底，标题 mono `--fs-xs`。
- **图片**：`--r-md`，发丝线描边，图注 `--fs-sm` `--ink-muted` 居中；列表缩略图 16:10，`--r-md`，hover 放大 1.03。
- **Mermaid**：跟随主题；hover 出现幽灵控制（+ / − / 复位 / 全屏），滚轮/双指缩放、拖拽平移、双击复位。
- **评论**：头像 28px 圆形，名字 + mono 日期为 meta 行，评论之间发丝线分隔，正文用文章排版缩小一级（`--fs-ui`）；底部胶囊按钮「在 GitHub 上留言 ↗」。
- **Dock**：胶囊容器、毛玻璃、`--shadow-float`；圆形彩色图标（白色 1.5px 线性图标 + 顶部高光 + 细描边）；悬停放大无回弹；跨页面保持不重置。
- **页脚**：两栏基线对齐，mono `--fs-xs` 弱色，移动端单列居中。

## 8. 深色模式

由 `:root[data-theme='dark']` 切换，组件不写死颜色，只换令牌；深色下降低饱和与亮度，阴影改为纯黑透明，代码高亮主题 `github-dark-dimmed`。

## 9. 可访问性

- 正文对比度 ≥ 7:1，meta ≥ 4.5:1；不用颜色作为唯一信息。
- 焦点环：`2px solid var(--accent)`，offset 2–3px，所有可交互元素可键盘到达。
- 图标按钮必须有 `aria-label`；点击区域 ≥ 32px。
